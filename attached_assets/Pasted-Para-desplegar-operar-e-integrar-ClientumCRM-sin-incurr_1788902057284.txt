Para desplegar, operar e integrar **ClientumCRM** sin incurrir en costos de suscripción ni licencias de software, se detalla un mapa exhaustivo de **alternativas 100% gratuitas (Free Tier permanente o Self-Hosted)** para cada capa de la arquitectura, servicios externos, IA y módulos del sistema.

---

## 1. Inteligencia Artificial y Modelos Generativos

Actualmente, el sistema requiere la clave `GEMINI_API_KEY` para los módulos Copilot, CMO, Agentes IA, SDR Outreach y Estrategias GTM.

| Función / Uso | Proveedor / Servicio | Capa Gratuita / Free Tier | Alternativa Self-Hosted (Local) |
| --- | --- | --- | --- |
| **API de IA Principal** (Remplaza `GEMINI_API_KEY`)

 | **Google AI Studio** | **Gratis** (hasta 15 RPM / 1M TPM en Gemini 1.5 Pro/Flash). Generación de claves de API sin tarjeta de crédito. | **Ollama** o **LM Studio** ejecutando modelos open-source como `Llama-3.1-8B`, `Mistral-7B` o `Qwen-2.5`. |
| **Enrutador / Aggregator de IA** | **OpenRouter.ai** | Incluye acceso a modelos gratuitos (e.g., `meta-llama/llama-3-8b-instruct:free`, `mistralai/mistral-7b-instruct:free`). | **LiteLLM** (Proxy local para estandarizar APIs compatibles con OpenAI). |
| **Agentes Autónomos & Workflows de IA** | **n8n Community Edition** | Planes Cloud tienen costo, pero la versión self-hosted es totalmente gratuita y sin límites de ejecución. | **Flowise AI** o **Langflow** (Constructores visuales de agentes IA locales). |

## 2. Base de Datos, Persistencia y Backend

El proyecto utiliza Firebase en el frontend y referencia la administración automática de base de datos en Replit.

| Módulo / Requisito | Opción Cloud Free Tier | Opción Self-Hosted / Open Source |
| --- | --- | --- |
| **Base de Datos Relacional / Documental** | **Supabase Free Tier** (500 MB PostgreSQL, Auth, Realtime) o **Neon.tech** (0.5 GiB PostgreSQL). | **PostgreSQL** o **MongoDB Community Edition** desplegado en un VPS propio o Docker local. |
| **Autenticación de Usuarios** | **Firebase Auth Free Tier** (hasta 50,000 MAU para Email/Password y Google Sign-In).

 | **Supabase Auth**, **Clerk** (plan gratuito hasta 10k MAU) o **Keycloak**. |
| **Base de Datos Serverless edge (D1 / Webmail)**<br> | **Cloudflare D1 Free Tier** (hasta 5,000,000 lecturas y 100,000 escrituras diarias gratis).

 | **SQLite** local montado en el contenedor del servidor Node.js/Express. |
| **Almacenamiento de Archivos / adjuntos** | **Cloudflare R2** (10 GB al mes gratis, sin costos de egreso de ancho de banda). | **MinIO** (Servidor de almacenamiento de objetos compatible con AWS S3). |

## 6. Arquitectura General Recomendada "Zero-Cost"

Para operativizar **ClientumCRM** sin gasto de infraestructura:

```
                           ┌────────────────────────────────────────┐
                           │      Navegador Web del Usuario         │
                           └──────────────────┬─────────────────────┘
                                              │
                      ┌───────────────────────┴───────────────────────┐
                      ▼                                               ▼
   ┌────────────────────────────────────┐          ┌────────────────────────────────────┐
   │     Frontend (React + Vite)        │          │    Backend (Node.js / Express)      │
   │  Alojado en: Cloudflare Pages /    │          │    Alojado en: Render / Koyeb       │
   │  Vercel Free Tier                  │          │    Free Tier                       │
   └──────────────────┬─────────────────┘          └──────────────────┬─────────────────┘
                      │                                               │
        ┌─────────────┴─────────────┐                   ┌─────────────┴─────────────┐
        ▼                           ▼                   ▼                           ▼
┌───────────────┐           ┌───────────────┐   ┌───────────────┐           ┌───────────────┐
│ Auth & Data   │           │ Maps Client   │   │ IA Generativa │           │ WhatsApp /    │
│ Supabase /    │           │ OpenStreetMap │   │ Google AI     │           │ Mensajería    │
│ Firebase Free │           │ + Leaflet     │   │ Studio API    │           │ Evolution API │
└───────────────┘           └───────────────┘   └───────────────┘           └───────────────┘

```

1. **Frontend:** Desplegado en **Cloudflare Pages** o **Vercel** enlazado a un repositorio público/privado de GitHub.


2. **Backend:** Ejecutado en **Render** o en un servidor local mediante **Coolify**.
3. **Motor de IA:** Consumo de la API gratuita de **Google AI Studio** (`GEMINI_API_KEY`).


4. **Base de Datos & Auth:** **Supabase Free Tier** o **Firebase** para almacenamiento y sesiones de usuario.


5. **WhatsApp & Mensajería:** Instancia local de **Evolution API** vinculada por código QR.
