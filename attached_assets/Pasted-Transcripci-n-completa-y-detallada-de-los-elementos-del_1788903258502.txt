CUALES NECESITAS API KEYS PARA OBETENR DATOS REALES

Los módulos que requieren integración mediante API Key o credenciales de conexión externa para sincronizar y obtener datos en tiempo real son:

COMUNICACIÓN Y CRM

    WhatsApp CRM & Chatbot 24/7: Requiere API Key / Access Token de la WhatsApp Business Platform API (Meta Graph API) o proveedor de BSP (como Twilio, MessageBird, etc.).

    Webmail Cloudflare (GTM): Requiere Cloudflare API Token para gestión de registros DNS/Email Routing y credenciales SMTP/IMAP para correo.

OPERACIONES & CONFIGURACIÓN

    Facturación AFIP (CAE): Requiere certificado digital (.crt), clave privada (.key) y autenticación vía Web Services de AFIP (WSAA / WSFEv1).

    Cobros MercadoPago: Requiere AccessToken / Secret Key de la API de MercadoPago (producción o Sandbox).

    Prospección Mapa B2B: Requiere API Key de Google Maps Platform (Places API / Geocoding API).

    Gestor de Dominios: Requiere API Keys del registrador de dominios (Cloudflare API, GoDaddy, Namecheap, etc.).

INTELIGENCIA ARTIFICIAL

    Asistente Gemini 1.5 & Agent OS: Requieren Google AI Studio API Key (para Gemini) o claves de proveedores LLM según el modelo utilizado (OpenAI, Anthropic, etc.).

Módulos que NO requieren API Keys externas (operan directamente con la base de datos interna del sistema):

    Resumen Ejecutivo, Pipeline Negocios, Empresas, Contactos, Tareas, Calendario, Reportes, Lead Scoring, Workflows internos, Custom Objects, CSV Import/Export y Configuración General.
