A continuación se presenta una guía práctica y estructurada para reemplazar cada componente pago o dependiente de la nube por **alternativas 100% gratuitas y sin límites de pago**, utilizando servicios con *Free Tier* perpetuo o componentes *Open Source* que pueden ejecutarse de forma local o autocanjeada (Self-Hosted).

---

## 1. Núcleo, Inteligencia Artificial y Agentes

Para eliminar la dependencia de un plan pago de modelos de lenguaje o evitar costos por token:

* **Inferencia de IA sin costo (API Cloud):**
* **Google AI Studio (Gemini 1.5 Flash / Pro):** Otorga un plan gratuito de hasta 15 solicitudes por minuto (RPM) y 1.000.000 de tokens por minuto (TPM). Permite generar la `GEMINI_API_KEY` sin ingresar tarjeta de crédito.
* **OpenRouter (Modelos Free):** Funciona como enrutador y ofrece acceso a modelos como `meta-llama/llama-3.1-8b-instruct:free` o `mistralai/mistral-7b-instruct:free`.


* **Motor de IA Local / Self-Hosted (100% Privado):**
* **Ollama / LM Studio:** Permite ejecutar modelos *Open Source* (Llama 3.1, Mistral, Qwen 2.5) localmente en un servidor o máquina de desarrollo. Expone una API compatible con OpenAI para conectar directamente al backend Node.js (`/api/ai/*`).


* **Automatización y Agentes:**
* **n8n Community Edition / Flowise AI:** La versión *self-hosted* en Docker es gratuita e ilimitada para crear orquestaciones complejas de agentes y conectar webhooks.

## 2. Base de Datos, Autenticación y Almacenamiento

Sustitutos sin cargo para PostgreSQL de pago o almacenamiento en la nube:

* **Base de Datos Relacional (PostgreSQL):**
* **Supabase (Tier Gratuito):** Incluye 500 MB de base de datos PostgreSQL, panel visual, cliente API y extensión Vectorial (`pgvector`) para búsquedas semánticas.
* **Neon.tech:** Proporciona un clúster serverless de PostgreSQL gratuito (hasta 0.5 GiB de almacenamiento y cómputo *Always-On*).


* **Autenticación de Usuarios:**
* **Firebase Auth / Supabase Auth:** Manejan hasta 50.000 usuarios activos mensuales (MAU) sin costo para inicio de sesión por correo/contraseña y proveedores OAuth (Google, GitHub).


* **Almacenamiento de Archivos (Object Storage):**
* **Cloudflare R2:** Proporciona 10 GB de almacenamiento mensual y lecturas/escrituras masivas sin cobro de ancho de banda (egreso de datos gratis).
* **MinIO (Self-Hosted):** Servidor de almacenamiento de objetos compatible con la API de Amazon S3 para instalar en un servidor propio.



---

## 3. Mensajería, Correo y Notificaciones

Opciones para evitar pasarelas SMS o APIs de pago:

* **WhatsApp CRM & Chatbots:**
* **Meta WhatsApp Cloud API (Oficial):** La capa gratuita de Meta incluye **1.000 conversaciones iniciadas por usuarios al mes** de forma gratuita.
* **Evolution API / Baileys (Gratis e Ilimitado - Self-Hosted):** Motores de código abierto en Node.js que convierten cualquier número de WhatsApp (personal o Business) en una API mediante código QR, omitiendo las comisiones por mensaje.


* **Emails Transaccionales y Campañas:**
* **Brevo (Sendinblue):** Permite enviar hasta 300 correos electrónicos diarios en su plan gratuito permanente.
* **Cloudflare Email Routing + Workers:** Permite redirigir correos entrantes de un dominio propio hacia casillas personales o almacenarlos en una base de datos Cloudflare D1 sin costo.


* **Notificaciones SMS sin costo:**
* **Android SMS Gateway:** Aplicaciones de código abierto que transforman un teléfono móvil Android en un servidor backend de SMS, aprovechando los paquetes de mensajes ilimitados de la SIM telefónica.

## 4. Facturación, Cobros y Servicios Locales

Servicios para operar comercialmente en Argentina sin tarifas mensuales fijas:

* **Facturación Electrónica AFIP (CAE):**
* **Conexión Directa WSAA / WSFEv1:** Utilizar la librería *Open Source* `afip.js` para consumir los Web Services SOAP oficiales de la AFIP. Los certificados digitales (`.crt` y `.key`) se tramitan de forma gratuita mediante Clave Fiscal en el portal de la AFIP.


* **Pasarela de Cobros (Mercado Pago):**
* **Mercado Pago API Directa:** Sin costo de mantenimiento mensual ni suscripción. Solo descuenta la comisión por cobro realizado. El entorno *Sandbox* de pruebas es 100% gratuito.
